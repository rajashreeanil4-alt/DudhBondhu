# DudhBondhu Android Project

This is an Android Studio-ready WebView wrapper for the DudhBondhu MVP.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).

The generated APK will normally be under:
`app/build/outputs/apk/debug/`

OTP validation is intentionally not included in this MVP.
